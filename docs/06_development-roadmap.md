# 開発ロードマップ

## 1. 基本方針

- 現在は仕様検討段階であり、実装コードは作成しません。
- 業務モデル、用語、利用者、権限、画面、データ項目を整理してから実装します。
- 2コートの実証運用を最初の到達点とします。
- 各段階を小さく分け、レビューとテストを行います。

## 2. フェーズ

### Phase 0: 構想・要件整理（現在）

- プロジェクト目的と対象範囲の整理
- 利用者と役割の整理
- ユーザー・認証機能の要件整理
- イベント運営業務の整理
- コート、試合、マーカーの用語整理
- 表示・配信・スポンサー要件の整理
- お名前.com RSプランの制約確認

成果物:

- プロジェクト概要
- システム構成
- サービス・業務領域計画
- 配信・ネットワーク計画
- 未決定事項一覧

### Phase 1: 基本設計

- 画面一覧と画面遷移
- 権限・ロール設計
- ドメインモデル
- データベース概念・論理設計
- API設計
- リアルタイム更新方式の選定
- 認証・アカウント復旧設計
- 開発・検証・本番環境とデプロイ設計

### Phase 2: 基盤・認証

- CakePHP / Vue.jsの開発基盤
- ユーザー登録

### Phase 3: イベント運営

- イベント基本情報
- カテゴリー

- スタッフ管理

### Phase 4: 試合・コート

- コート・施設管理

### Phase 5: マーカー・リアルタイム表示

- コートごとのYouTubeライブ

初期リリースの正確な範囲は検討中です。現時点では次を候補とします。

- ユーザー登録・ログイン
- イベント・カテゴリー管理
- 選手・スタッフ管理
- コート・試合管理
- マーカー
- 観客用得点表示
- OBSオーバーレイ
- 大会ロゴ・スポンサーロール

エントリー受付、ドロー自動作成、通知、ランキングを初期リリースに含めるかは検討中です。

## 4. 先に決める事項

1. 「イベント」「大会」「カテゴリー」「ゲーム」「試合」の用語と関係
2. ユーザー、参加者、選手、スタッフ、運営管理者の関係
3. 個人戦・団体戦・複数カテゴリーへの対応範囲
4. 権限と承認フロー
5. エントリー、参加費、キャンセルの範囲
6. スコア方式と訂正・確定フロー
7. リアルタイム更新方式
8. 通知方法
9. 個人情報・セキュリティ・保存期間
10. 初期リリースの必須機能
