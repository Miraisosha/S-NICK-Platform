# ダッシュボード

## 検討状態

本機能のうち、ログイン後に表示するダッシュボードの詳細は、イベント管理、試合管理、スタッフ権限、通知等の仕様に応じて表示内容と優先順位が変わるため、現段階では**検討保留**とする。他の主要機能が固まった段階で再設計する。

ただし、ログイン後のトップ画面またはユーザーメニューに「クイック起動」ボタンを1つ設置することは**決定済み**とし、フェーズ1から提供する。

クイック起動以外の表示内容は確定仕様ではなく、再検討時の参考候補とする。

## SCR-OPR-231 運営者メニュー

ログイン後に次を表示する。

- クイック起動（フェーズ1から表示）
- 最近利用したイベント
- 運営中・開催間近のイベント
- 開催中または近日開催予定の注目試合
- 自分が担当する本日の業務・コート
- 申込締切、未決済、ドロー未公開、試合遅延等の要対応件数
- 招待、運営連絡、システム通知
- イベント新規作成、コート管理、ユーザー設定への導線

「クイック起動」を押した場合は、事前入力画面や確認画面を経由せず、空のクイック試合を作成して`SCR-MKR-321 マーカー画面`を直ちに表示する。イベント名、カテゴリ名、ラウンド名、コート番号および選手名が未入力でも得点操作を開始できる。

「最近利用した」の判定方法、「注目試合」の選定基準、表示件数、表示順、手動固定を含む、クイック起動以外の画面構成・表示項目・優先順位は検討保留とする。
