# 認証メール送信

## SCR-OPR-215 メール送信基盤

- ユーザー登録確認、パスワード再設定、アカウント変更通知等はSMTPで送信する。
- SMTPメールサーバーはWebサーバーとは別に用意する。
- SMTP認証と暗号化通信を使用する。
- 接続先、ポート、認証情報等は環境設定で管理し、設計書、ログ、Gitへ保存しない。
- 送信日時、宛先種別、メール種別、結果、失敗理由を記録する。パスワードやトークン本体は記録しない。

### SMTP環境設定

| 環境変数 | 用途 | 取扱い |
|---|---|---|
| `SMTP_HOST` | SMTPサーバーの接続先 | 環境ごとに設定する |
| `SMTP_PORT` | SMTPサーバーの接続ポート | 暗号化方式に対応するポートを設定する |
| `SMTP_USERNAME` | SMTP認証に使用するユーザー名 | 環境ごとに設定する |
| `SMTP_PASSWORD` | SMTP認証に使用するパスワード | 秘密情報として管理する |
| `EMAIL_FROM` | 送信元メールアドレス | 送信ドメイン認証と整合する値を設定する |

- SMTP通信は常に暗号化する。暗号化なしの接続は使用しない。
- 465番ポートを使用する場合は暗黙的TLS、587番ポートを使用する場合はSTARTTLSを必須とする。
- `SMTP_PASSWORD`はCakePHPの通常設定ファイル、設計書、ログ、Gitへ記載しない。
- 開発・検証・本番で接続先、認証情報および送信元を分離し、環境変数またはGit管理外の環境別設定から読み込む。
- 接続タイムアウト、送信失敗時の再試行回数と間隔はCakePHPのSMTP・キュー設定として実装時に定義し、本番相当環境で試験する。
- SPF、DKIM、DMARC等の送信ドメイン認証はCakePHPだけでは完結しないため、お名前.com側のメールサーバーとDNSで設定・確認する。
