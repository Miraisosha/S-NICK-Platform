# 2000 運営者

## 目的

運営者とイベントスタッフが、大会準備、当日進行、結果確定、参加選手への連絡およびイベント問い合わせへの対応を行う。

## 利用端末・レスポンシブ方針

- PCブラウザを主用途とし、一覧、検索条件、詳細および操作を効率よく確認できるようにする。
- 大会当日の緊急対応を考慮し、タブレットとスマートフォンからも主要操作を継続できるレスポンシブ表示とする。
- 画面幅を理由に権限、確認手順または監査記録を変えない。
- ドラッグ＆ドロップだけに依存せず、タッチ端末やキーボードでも実行できる代替操作を提供する。
- 対戦選手の表示は`Player A vs Player B`形式に統一する。

共通の配色、文字、操作部品およびレスポンシブ設計は[フロントエンド](../../architecture/301_frontend.md)を参照する。
