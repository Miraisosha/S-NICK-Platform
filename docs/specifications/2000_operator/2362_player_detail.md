# 選手詳細

## 位置づけ

イベントへ登録された参加選手の基本情報、参加カテゴリ、ドロー順位、試合予定、結果および連絡履歴を確認する。参加選手一覧は[2361 参加選手管理](2361_participant_management.md)を参照する。

## 表示候補

- 選手名、表示名、所属
- 対象イベントと参加カテゴリ
- 申込・受付状態
- ドロー順位、シード情報
- 試合予定と結果
- 個別メールの送信履歴
- 操作履歴

## 権限

個人情報は、対象イベントで閲覧権限を持つ運営者・スタッフだけが確認できる。パブリックへ表示する項目と運営者だけが参照する項目を分離する。

## 検討中

- 編集可能項目と選手本人のプロフィールとの優先関係
- フェーズ1の手動登録選手とフェーズ3のユーザーアカウントの関連付け
- 個人情報の保存期間とマスキング
