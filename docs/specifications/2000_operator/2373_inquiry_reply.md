# 問い合わせ返信

## 目的

イベント運営者が問い合わせへ返信し、対応履歴を残す。

## 基本方針

- 返信は問い合わせのメッセージ履歴へ追加する。
- 過去の質問や返信を上書き・削除しない。
- 返信者、返信日時、送信結果を記録する。
- 保存成功後に通知処理を行い、通知失敗時も返信履歴を維持する。

## 操作候補

- 返信本文の入力
- 送信前確認
- 下書き保存
- 返信送信
- 回答済みまたは完了への状態変更
- 送信失敗時の再送

## 検討中

- メール本文と画面表示本文の関係
- 定型文・署名
- 添付ファイル
- 複数担当者による同時返信の競合防止
- 送信後に訂正が必要な場合の扱い
