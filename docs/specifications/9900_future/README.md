# 9900 将来構想

## 位置づけ

フェーズ1～4へ導入時期を確定していない機能候補を管理する。候補を実装範囲へ移す場合は、対象グループの機能仕様へ詳細を追加する。

## 機能候補

- 未成年選手の保護者同意、代理申込、緊急連絡先
- 個人情報、申込、結果、監査履歴等の保存期間
- 協会会員番号によるランキング照合
- 団体戦、予選から本選への自動連携
- 紙のマーカー用紙からの結果一括登録
- 指定時点へのデータ復旧
- 主催団体によるイベント所有
- 複数団体・複数会場への拡張
- 外部認証
- 詳細な異議申立て・上申管理
- 回線ボンディング
- 高度な配信アーカイブ管理

## マニュアル・QA

操作マニュアルはフェーズ4で提供する。QA検索は候補とし、詳細は[マニュアル・QA](../9000_common/9801_manual_qa.md)で管理する。

## イベント問い合わせ

イベントごとの問い合わせ送信・管理を行う方針は決定済みとし、[イベント問い合わせ](../2000_operator/2370_event_inquiries.md)で管理する。導入フェーズ、利用者範囲、通知および担当ロールは検討中である。

## 原則

将来機能は現在の設計を不必要に複雑化させない。拡張可能性を考慮しつつ、現在のフェーズに必要なデータと処理を優先する。
