# 用語集

| 用語 | 定義 |
|---|---|
| イベント | S-NICK上で管理する一つの大会・開催単位 |
| カテゴリ | イベント内の競技区分 |
| ドロー | 対戦組合せ・勝ち上がり構造 |
| マーカー | 試合の得点と進行を記録する担当者 |
| マーカーボード | マーカーが得点や試合イベントを入力する画面 |
| 大型表示 | 会場モニター等へ表示する得点・日程画面 |
| OBSオーバーレイ | OBSのBrowser Sourceで映像上に重ねる表示 |
| アクセス種別 | `ReadOnly` または `Write` で示す機能の操作区分 |
| イベント | ボタン、リンク、入力等を起点に実行される処理 |
| 業務ルール | イベント時に守る判定・更新・制約 |
| Single Source of Truth | 要件・設計の正本として参照する唯一の情報源 |
