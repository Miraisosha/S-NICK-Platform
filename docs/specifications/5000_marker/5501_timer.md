# ウォームアップ・タイマー

## 350 ウォームアップ・試合準備・タイマー

### 設定値

| 項目 | 設定 |
|---|---:|
| ウォームアップ左側 | カテゴリ設定。初期値120秒 |
| ウォームアップ右側 | カテゴリ設定。初期値120秒 |
| 試合開始前インターバル | カテゴリ設定。初期値60秒 |
| ゲーム間インターバル | カテゴリ設定。初期値120秒 |
| Injury Time | 操作時に30～900秒を30秒刻みで選択 |

ウォームアップとインターバルの設定値はカテゴリ単位とし、対象試合のカテゴリ設定を使用する。

### 表示・動作

- 円が時間経過に伴って欠けるカウントダウンを表示する。
- 数字の残り時間も併記する。
- 一時停止、スキップ、終了操作を用意する。
- タイマー終了時は設定に応じて音・振動・画面表示で通知する。
- 左側ウォームアップ終了後は右側ウォームアップへ進む。
- 右側ウォームアップ終了後は試合開始前インターバルへ進む。
- 試合開始前インターバル終了後は自動開始せず、マーカーが`試合開始`を押して第1ゲームを開始する。
- 各ゲーム終了後、試合が継続する場合はゲーム間インターバルへ進む。必要ゲーム数を先取して試合が終了した場合はインターバルを開始しない。
- Injury Time開始時は対象選手を確認し、30～900秒の範囲から30秒刻みで審判が指定した時間を選択してカウントダウンを開始する。
- タイマーは単純な1秒減算ではなく、終了予定時刻と現在時刻から残り時間を計算する。

### ブラウザ終了後のタイマー復元

- タイマーの開始、一時停止、再開、スキップ、終了の各操作時に、タイマー種別、状態、設定時間、開始日時、終了予定日時、一時停止時の残り時間、最終更新日時をサーバーと端末内へ直ちに保存する。
- 作動中にブラウザを閉じてもタイマーを一時停止したものとは扱わず、終了予定日時までは実時間が経過したものとして扱う。
- 同じ端末・同じブラウザで再起動した場合、作動中タイマーの残り時間は `max(0, 終了予定日時 - 現在日時)` で再計算し、320 マーカー画面へ表示する。
- 一時停止中にブラウザを閉じた場合は、保存した残り時間のまま復元し、再開操作後に新しい終了予定日時を設定する。
- 再起動時点ですでに終了予定日時を過ぎている場合は残り時間を0とし、タイマー終了を明示する。ブラウザが閉じていた間の通知音・振動は再現せず、復帰時に画面上で未確認の終了を通知する。
- ブラウザ不在中に自動進行させるのは、ブラウザを閉じた時点で作動していた1つのタイマーが0になるまでとする。次のタイマー、次ゲーム、試合開始または試合再開へ連続して自動遷移させない。
- タイマーの終了予定日時より前に復帰した場合は、残り時間を復元して同じ状態を継続する。
- 終了予定日時を過ぎてから復帰した場合は、残り時間0と「時間終了」を表示し、次に必要な操作を大きなボタンで案内する。
- 左側ウォームアップの終了後は「右側ウォームアップ開始」、右側ウォームアップの終了後は「試合開始前インターバル開始」を表示し、マーカーの確認操作後に次のタイマーを開始する。
- 試合開始前インターバルの終了後は`preparing`のまま「試合開始待ち」とし、マーカーが`試合開始`を押すまで第1ゲームを開始しない。
- ゲーム間インターバルの終了後は`interval`のまま「次ゲーム開始待ち」とし、マーカーが`次ゲーム開始`を押すまで次ゲームを開始しない。
- Injury Timeの終了後は`injury_time`のまま「審判判断待ち」とし、試合再開、追加時間、棄権、試合授与等を審判・マーカーが選択するまで試合を自動再開しない。

### 端末時刻の確認とタイマー補正

- オンライン時にサーバー時刻を取得し、通信の往復時間を考慮して端末時刻との差分を算出する。タイマーの現在日時には端末時計そのものではなく、確認済みのサーバー時刻差分を加味した補正後日時を使用する。
- 時刻差分は、マーカー起動時、WebSocket再接続時、タイマーの開始・再開前、およびWebSocketの定期通信時に確認する。
- サーバー時刻との絶対差が5秒未満の場合は警告を表示せず、サーバー時刻差分を更新してタイマー表示へ反映する。
- 絶対差が5秒以上の場合は、「端末時刻がサーバー時刻と○秒ずれています」と表示する確認ダイアログを開く。ダイアログには補正前後の残り時間を表示する。
- ダイアログの「サーバー時刻で補正して続行」を選択した場合は、端末本体の時計を変更せず、システム内の時刻差分を更新して残り時間を再計算する。
- 「端末の日時設定を確認」を選択した場合は、端末設定を確認してから再検出できるようにする。ブラウザから端末本体の日時設定を直接変更しない。
- 時刻補正によってタイマーが0以下になった場合は0と「時間終了」を表示するが、次のタイマー、ゲーム、試合開始または試合再開へ自動遷移しない。
- オフライン中は最後に確認したサーバー時刻差分を使用する。通信復旧時に再検出し、5秒以上の差があれば同じ確認ダイアログを表示する。
