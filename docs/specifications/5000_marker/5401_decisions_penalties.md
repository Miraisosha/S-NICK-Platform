# アピール・ペナルティ

## 340 アピール・ペナルティ

左右の判定ボタンは、通常判定ではその側をストライカーとして扱う。Conduct系では、その側をペナルティ対象選手として扱うため、確定前に対象選手名、色、処理結果を必ず表示する。

### 基本判定

| 操作 | 処理 | サーブ処理 |
|---|---|---|
| YES LET | 得点変更なし、`YES_LET`を記録 | 同じサーバー、同じボックス |
| NO LET | アピールした選手の相手へ1点 | 通常のポイント処理 |
| STROKE | ストライカーへ1点 | 通常のポイント処理 |

### その他判定

| 操作 | 処理 | 確認 |
|---|---|---|
| CONDUCT WARNING | 対象選手への警告と理由を記録 | 対象選手を表示 |
| CONDUCT STROKE | 対象選手の相手へ1点 | 対象選手と加点先を表示 |
| CONDUCT GAME | 対象選手の相手へ現在ゲームを授与 | 必須 |
| CONDUCT MATCH | 対象選手の相手へ試合を授与して終了 | 必須 |
| INJURY TIME | 対象選手と選択時間でカウントダウン | 必須 |
| FORFEIT MATCH | 相手を勝者として試合終了 | 必須、理由入力 |

Conduct Gameでは現在ゲームを`awarded`として相手へ授与し、未実施ポイントを加算して架空の最終得点を作らない。ゲーム結果には得点とゲーム授与を併記する。

Injury Timeのフェーズ1選択肢は30秒から900秒（15分）までの30秒刻みとし、審判がその場で判断した時間をプルダウンから選択する。公式ルール上、自己起因の負傷は最大180秒（3分）、双方関与または相手による偶発的負傷は最大900秒（15分）となるため、審判は判定した負傷区分の上限内で時間を選択する。

血液を伴う負傷も別の状態やタイマーを設けず、`Injury Time`として記録・計測する。回復時間および再発時に新たなInjury Timeを認めるかは審判が公式ルールと大会規則に基づいて判断し、認める場合は同じ30～900秒のプルダウンから時間を選択する。システムは審判の判断を自動的に上書きしない。

Injury Timeの区分と上限は [World Squash Singles Rules 2025 Rule 13](https://worldsquashofficiating.com/rules-of-squash/) を基準とする。確認日は2026年8月7日とし、実装時に採用大会のルール版を再確認する。

### マーカーボード上の判定表示

- 判定は対象側の2列を結合した専用行として表示する。
- 表示文字は`YES LET`、`NO LET`、`STROKE`、`WARNING`、`C.STROKE`、`C.GAME`、`C.MATCH`、`INJURY`、`FORFEIT`等とする。
- 判定種別ごとに背景を区別するが、色だけに依存しない。
- 得点を伴う判定では、判定行に続けて次のサーブ状態を通常行で表示する。
