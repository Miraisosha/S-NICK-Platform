# 多言語

- マーカー画面の多言語対応はフェーズ3で導入する。フェーズ1・2は日本語を基本とするが、フェーズ3で作り直しにならない画面構造とする。
- フェーズ3の初期対象言語は日本語`ja`、英語`en`、韓国語`ko`とする。
- 固定文言をソースへ直接埋め込まず、翻訳キーで管理する。
- ラウンド等は共通管理コードと表示名を分離する。
- ボタンは翻訳後の文字列が日本語の約1.3倍になっても収まる余白を基本とする。画面幅または翻訳文字列の長さにより収まらない場合は、2行までの折返しと文字縮小を行い、省略記号だけで操作名を隠さない。
- 得点、ゲーム数、`L`／`R`等の競技記号は言語変更の影響を受けない領域として扱い、翻訳文字列の長さで得点領域が縮まないようにする。
- イベント設定でマーカー画面の既定言語を1つ選択し、そのイベントで初めて使用する端末はイベント既定言語で表示する。
- マーカー画面から端末ごとに表示言語を変更できる。選択内容は利用者アカウント単位ではなく「端末×イベント」単位で保存し、同じ端末で同じイベントを再度開いたときに復元する。
- 端末で言語を個別設定していない場合は、イベント既定言語の変更へ自動的に追従する。個別設定済みの端末はその設定を維持する。
- 言語選択に「イベント既定値を使用」を用意し、端末の個別設定を解除してイベント既定言語へ戻せるようにする。
- クイックモード等でイベント設定がない場合は日本語`ja`を初期値とし、端末で選択した言語を対象のクイック試合に保存する。
- オフライン中も保存済みの端末言語を使用し、言語変更によって得点・試合状態・操作履歴を変更しない。
- 右から左へ記述する言語には対応しない。対応言語を追加する場合も左から右の表示を前提とし、選手領域、得点、操作ボタンおよび画面遷移の左右を反転しない。
- 大型得点ボードへ表示する`YES LET`、`NO LET`、`STROKE`は英大文字に固定する。その他の競技判定を英語固定とするかは検討中。
