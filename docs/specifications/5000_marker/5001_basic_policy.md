# マーカー基本方針

## 目的

担当試合を安全かつ素早く進行し、得点、サーブ、判定、タイマー、試合結果を記録する。確定した状態は、大型表示、観客画面、OBSオーバーレイへリアルタイムに反映する。

マーカー機能はSquash Platformの中核機能とし、操作の速さよりも、誤操作時に完全に復元できること、通信障害やブラウザ終了で状態を失わないことを優先する。

## 301 基本方針

### 対象端末

- スマートフォン、タブレットのブラウザを主対象とする。
- 大会運用ではコートごとにマーカー操作用タブレットを1台設置する。
- コート別大型得点ボードは、コートごとに1～2台の閲覧専用端末を設置する想定とし、マーカー操作用タブレットとは分離する。
- タッチ操作を前提とし、ボタン、文字、タップ領域を大きくする。
- 縦画面と横画面に対応し、回転しても試合状態を維持する。
- 主要操作は可能な限り一画面に収める。
- フォントは日本語・英語・韓国語で視認性の高いサンセリフ体を使用する。
- 色だけで状態や対象選手を識別させず、名前、ラベル、アイコンを併用する。

### 動作モード

| モード | 内容 |
|---|---|
| 通常モード | 登録済みのイベント、カテゴリ、試合、選手情報から開始する |
| クイックモード | イベントを作成せず、ログイン後のクイック起動ボタンから直ちにマーカーを利用する |

クイックモードは初期リリースから提供する重要機能とし、そのリリース時点で通常モードに提供されているマーカー関連機能をすべて利用できるようにする。OBS、多言語、音声等の後続フェーズ機能も、それぞれの提供開始時から通常モードとクイックモードの両方で利用可能にする。

### クイックモードの開始と機能範囲

- ログイン後のトップ画面またはユーザーメニューに「クイック起動」ボタンを1つ設ける。
- 「クイック起動」を押すと、事前入力画面や確認画面を経由せず、クイック試合を作成して`SCR-MKR-321 マーカー画面`を直ちに表示する。`SCR-MKR-311 コート別当日試合一覧`は経由しない。
- イベント、カテゴリ、ドローおよびスケジュールを事前作成せずに利用できる。イベント名、カテゴリ名、ラウンド名、コート番号および左右の選手名は空欄を許可し、すべて空欄でも得点操作を開始できる。
- 初期値は、最大ゲーム数`1`、ゲーム終了点`11`、必要点差`2点差`、左選手色を青、右選手色を赤とする。
- 最大ゲーム数は`1`、`3`、`5`、ゲーム終了点は`0`～`100`、必要点差は`1点差`または`2点差`を設定できる。ゲーム終了点`0`では各ゲームを手動終了する方式を使用する。
- マーカー画面の設定から、イベント名、カテゴリ名、ラウンド名、コート番号、選手名、選手色、最大ゲーム数、ゲーム終了点、必要点差および各タイマーを後から入力・変更できる。
- 得点入力後に最大ゲーム数、ゲーム終了点または必要点差を変更する場合の、既存得点・ゲーム結果への適用方法は検討中とする。
- ウォームアップ、試合開始前インターバルおよびゲーム間インターバルは初期値を自動設定し、マーカー画面の設定から変更できるようにする。
- 得点、サーブ権、サービスボックス、YES LET、NO LET、STROKE、Conduct、Injury Time、Forfeit、ゲーム・試合終了、UNDO、終了後の履歴リセット・再入力を通常モードと同じように利用できる。
- オフライン継続、ブラウザ再起動後の復元、タイマー復元、操作端末ロック、監査履歴およびリアルタイム同期を通常モードと同じように利用できる。
- 大型得点表示およびOBSはクイック試合用の識別子と接続先を発行し、イベント未作成でも通常モードと同じ表示・連携機能を利用できる。
- クイック試合の終了後も、試合結果、ゲーム別得点および操作履歴を保存して再表示できる。
- クイックモードで省略するのは、イベント、カテゴリ、ドローおよびスケジュールとの事前関連付けだけとし、マーカー機能自体を簡略化しない。
