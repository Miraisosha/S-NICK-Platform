# マニュアル・QA

## 導入時期

操作マニュアルはフェーズ4で提供する。

## 決定済み

- Squash Platformの操作方法を利用者向けに提供する。
- 実際の画面、利用者区分および権限に対応させる。
- 仕様変更時に内容を更新できる構成とする。

## QAの候補

- 質問、回答、カテゴリ、対象機能、検索用キーワード等を登録する。
- 利用者がキーワード等から既存QAを検索できるようにする。
- イベント問い合わせの内容から、個人情報やイベント固有情報を除外して一般化したQAを作成する運用を候補とする。

## イベント問い合わせとの関係

イベントごとの問い合わせ送信と管理は[2370 イベント問い合わせ](../2000_operator/2370_event_inquiries.md)を正本とする。本書では、全利用者向けマニュアルと一般化したQAだけを扱う。

## 検討中

- マニュアルの対象利用者、章構成、HTML・PDF・動画等の提供形式
- 言語、版管理および公開単位
- QAの公開範囲、公開前承認、検索方式、同義語および表記揺れ
- QAをSquash Platform内で構築するか外部サービスと連携するか
