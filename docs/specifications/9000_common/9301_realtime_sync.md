# 630 リアルタイム同期

- マーカー入力を大型表示、観客画面、OBSへ反映する。
- 310 コート別試合一覧は、公開済みスケジュール、コート変更、選手、棄権、試合状態、結果の変更をページ再読込なしで反映する。
- 得点・判定等の更新要求はHTTPS APIへJSONで送信し、サーバーで保存した状態を正式状態とする。WebSocketは保存済み状態の更新通知に使用する。
- WebSocket通知のデータ形式はJSONとし、少なくともイベント種別、対象ID、状態バージョンおよび発生日時を含める。
- 通常時の更新方式はWebSocketによるサーバー通知とする。WebSocketが切断された場合は自動再接続を行い、再接続までの間はAPIポーリングへ自動的に切り替える。
- WebSocket再接続時は最新状態をAPIで再取得してから通知受信を再開し、切断中の更新漏れを補完する。APIポーリングの間隔は設定可能とし、初期値は性能試験と会場ネットワーク試験で決定する。
- 再接続時はイベントIDと状態バージョンにより、重複イベントおよび順序逆転を検出する。
- 同一試合のオフライン操作が複数端末へ分岐した場合は、端末ごとの操作履歴を独立して保持し、自動統合や時刻順での混在を行わない。権限を持つ運営者が正式な1つの記録を選択する。
