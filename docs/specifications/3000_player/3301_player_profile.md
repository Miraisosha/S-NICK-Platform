# 選手基本登録・アカウント

## 410 認証・アカウント

- 共通ログイン、ログアウト、パスワード再設定
- プロフィール、メールアドレス、パスワードの変更
- 顔写真の登録、切り抜き、変更、削除
- 画像メタデータを除去し、表示用縮小画像を生成
- 登録した選手アイコンは、ドロー、公開スケジュール、得点表示、ライブ配信等の選手識別に使用できる公開プロフィール画像として扱う
- アイコン未登録時はマイカラーと表示名または氏名の頭文字から既定アイコンを生成する
- フェーズ3では、日本語・英語・韓国語の言語別に任意の音声読み上げ名を登録し、試合紹介やゲーム・試合結果の音声コールへ使用できるようにする
- 音声読み上げ名は表示名を変更せず、音声テストで発音を確認してから保存できるようにする

## SCR-PLY-411 退会

- 選手画面のユーザー設定から、運営者向けユーザー設定と共通の退会画面へ移動できるようにする。
- 参加申込、予定試合、確定済み結果等への影響を確認し、再認証と最終確認後に退会する。
- 退会完了後は全端末セッションと自動ログインを無効化する。
- アカウントは物理削除せず論理削除する。過去の申込、試合結果、操作履歴と、当時の表示名等の記録は履歴として保持する。
- 同じメールアドレスによる再登録方法と具体的な保存期間は将来検討とする。
