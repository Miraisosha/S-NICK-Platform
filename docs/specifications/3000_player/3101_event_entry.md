# イベント申込

## 420 エントリー

選手自身が操作する本機能はフェーズ3で導入する。フェーズ1では運営者が選手を手動登録し、フェーズ2では運営者側の受付状態管理を追加する。

- イベント・カテゴリの選択と申込
- 申込状態、決済状態、キャンセル等の確認
- フェーズ3の決済は申込ごとの外部決済を基本候補とする
- カード番号全体やセキュリティコードはSquash Platform側に保存しない

## SCR-PLY-421 参加申込フォーム

- パブリックのイベント詳細・カテゴリ一覧から、対象カテゴリの「申込」を選択して開く。
- 未ログインの場合はログイン画面へ移動し、認証後に選択していたイベント・カテゴリの申込フォームへ戻る。
- ログイン済み選手のプロフィールから、氏名、表示名、氏名読み、国・地域、郵便番号、住所、電話番号、メールアドレス等を初期表示する。
- フェーズ3では言語別の音声読み上げ名を任意入力できるようにし、未入力時は氏名読み、表示名、氏名の順に読み上げ候補を使用する。
- 所属団体、参加カテゴリ、参加資格の確認、必要な同意項目を入力する。
- カテゴリ固有の申込期間、定員、重複申込、キャンセル待ちの設定を検証する。
- 入力、確認、申込完了の順に進み、二重送信による重複申込を防止する。
- 申込時点の氏名、表示名、氏名読み、所属、住所、連絡先、メールアドレス、同意文書の版を申込情報として保持する。
- 申込フォーム上で変更した内容をプロフィールへ反映するかは検討中。
- 決済を使用する場合は外部決済画面へ移動し、カード番号全体やセキュリティコードをSquash Platformへ保存しない。

運営者による申込選手の確認・通知は[参加選手管理](../2000_operator/2361_participant_management.md)、公開側の申込導線は[カテゴリ・申込導線](../1000_public/1401_categories.md)を参照する。
