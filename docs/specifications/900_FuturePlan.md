# 900 将来構想

## 機能候補

- ランキングサービスの拡充
- 保険申込との連携
- アプリ通知、LINE等の通知チャネル
- 保存済み決済手段の安全な再利用
- ログイン端末管理
- 多言語対応
- 複数会場・多数コートへの拡張
- 高度な自動ドロー・時間割最適化
- 配信アーカイブと試合データの連携
- 大型モニター・OBSでのスポンサー動画表示
- 大型モニターでの選手呼出・緊急案内表示（入力方法、対象範囲、表示時間、優先順位、音声併用は検討中）
- S-NICK上のライブ配信一覧・設定（YouTube配信枠、視聴URL、公開状態、OBS・コート対応の管理）
- イベント間のスポンサー情報再利用・コピー
- 統計、分析、選手向けパフォーマンス情報

## 原則

将来候補は初期リリースの必須要件と混同せず、採用時に優先順位、費用、運用、安全性を再評価する。
