# パブリック概要

## 位置づけ

引き継ぎ元「パブリックダッシュボード仕様」で合意した、ログイン不要画面の要件を整理する。
公開ページは、イベントを探すところから、申込、当日観戦、結果・配信アーカイブの閲覧までを同じ導線で提供する。

## 導入フェーズ

- フェーズ1は、登録時に自動公開されたイベントの一覧・詳細、ドロー、日程、進行、得点、結果を対象とする。
- フェーズ2は、運営者側の受付・通知・ランキング利用に必要な公開情報を追加する。
- フェーズ3は、選手自身のWeb申込、詳細なイベント状態別表示、ライブ観戦、ランキング公開、過去イベント・配信アーカイブを追加する。
- `SCR-PUB-111`の申込受付中・過去等による高度な分類、`PUB-130`のWeb申込導線、`PUB-150`、`170 公開制御`の予約・限定・終了操作はフェーズ3とする。フェーズ1はカテゴリ閲覧と登録時の自動公開に対応し、トップは公開イベントを開催日時順に表示する。

## 目的

- 観客・選手・関係者が、現在開催中、申込受付中、開催予定、終了済みのイベントをすぐ見つけられるようにする。
- イベントの開催前・開催中・開催後で、必要な情報と操作を適切に切り替える。
- Squash Platformの試合状態を、会場表示、OBS、公開ページで一貫して利用する。
