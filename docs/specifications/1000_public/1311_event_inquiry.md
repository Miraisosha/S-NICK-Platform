# イベント問い合わせ

## 位置づけ

利用者がイベント詳細から、そのイベントの運営者へ問い合わせを送信する画面である。問い合わせは必ず対象イベントに所属し、運営者側の管理仕様は[2370 イベント問い合わせ](../2000_operator/2370_event_inquiries.md)を正本とする。

## 決定済み

- イベント詳細から問い合わせ画面へ移動する。
- 問い合わせは一つのイベントに所属する。
- イベントを特定しないシステム全体への問い合わせとは分離する。
- 送信済みの問い合わせ本文と返信は履歴として保持し、上書きしない。

## 入力候補

- 問い合わせ種別
- 氏名または表示名
- 返信先メールアドレス
- 件名
- 本文
- 対象カテゴリまたは申込情報

## 送信後

- 受付完了を表示する。
- 問い合わせを対象イベントの管理画面へ反映する。
- 受付番号を発行するかどうかは検討中とする。
- 受付メールおよび返信通知の方式は検討中とする。

## 検討中

- 未ログイン利用者からの送信可否
- ログイン済み選手のプロフィール・申込情報を引き継ぐ範囲
- 必須項目、文字数、添付ファイル
- スパム対策、レート制限および本人確認
- 導入フェーズ
