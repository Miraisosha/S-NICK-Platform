# ライブ観戦

## SCR-PUB-151 ライブ一覧・視聴

配信はイベント、開催日、会場、コート、試合の各単位へ関連付けられるようにする。

| 項目 | 内容 |
|---|---|
| 配信サービス | 初期対象はYouTube Live |
| URL・埋込情報 | 視聴URLと埋込に必要な識別情報 |
| 関連先 | 開催日、会場、コート、試合 |
| 時刻 | 配信予定、開始、終了 |
| 状態 | 予定、まもなく開始、配信中、終了、アーカイブ、配信中止 |
| 表示 | サムネイル、公開・非公開 |

配信中はライブ導線を目立たせ、固定されたSquash Platform側URLから対象配信へ案内する。YouTube・OBSの設定と運用は[ライブ配信](../9000_common/9702_live_streaming.md)を参照する。
